Global Constraints

  • Rust MSRV: 1.82 · #![forbid(unsafe_code)] at crate root
  • No print!() / eprintln!() — use log crate via pyo3-log
  • No .unwrap() at PyO3 boundary — .expect("reason") OK for internal invariants
  • Borrowed &str → owned String before py.allow_threads()
  • cargo clippy --all-targets -- -D warnings after every task
  • cargo fmt --check after every task
  • Commit after each TDD phase — never across task boundaries
